## Native vs React Native vs Flutter

| Compared on | Native (Swift and Kotlin) | React Native | Flutter |
|---|---|---|---|
| Codebases | Two, one per platform | One, in TypeScript | One, in Dart |
| Best for | Device-heavy features, graphics, latest platform APIs | Teams with a React web app or JavaScript skills | Custom, brand-led interfaces on both platforms |
| Look and feel | Fully native on each platform | Native components | Its own rendering, identical on both |
| Access to device features | Full, on day one | Broad, plus native modules when needed | Broad, plus platform channels when needed |
| Code shared with your web app | None | Logic and some UI with React | Limited |
| Cost of each change | Higher, done twice | Lower, done once | Lower, done once |
